# 🎲 NewSigmaRPG

Bem-vindo ao repositório oficial da documentação do **NewSigmaRPG**, um sistema de RPG de mesa genérico, flexível e focado na narrativa.

## 📖 O Que é o NewSigmaRPG?

O **NewSigmaRPG** foi projetado para ser um sistema leve e adaptável, perfeito para mestres que gostam de criar seus próprios mundos e para jogadores que buscam liberdade criativa. Diferente de sistemas complexos baseados em D20, o NewSigmaRPG utiliza o dado de 8 faces (**D8**) como núcleo de suas mecânicas, oferecendo uma experiência de jogo única, onde a média é mais constante e os acertos críticos (e falhas) são emocionantes.

### ✨ Destaques do Sistema

- **Mecânica Baseada em D8**: As ações são resolvidas rolando **2D8**, onde o sucesso depende da proximidade do resultado ao valor do atributo (intervalo base de -2 a +2), com perícias expandindo essa margem. Intuitivo, dinâmico e focado na narrativa.
- **Narrativa em Primeiro Lugar**: Regras enxutas que priorizam a fluidez da história em vez de tabelas intermináveis.
- **Sistema Agnóstico**: Funciona para Fantasia Medieval, Cyberpunk, Terror Sobrenatural, Faroeste ou Ficção Científica.
- **6 Arquétipos Versáteis**:
  - ⚔️ **Combatente**: Força bruta e tática.
  - 🛠️ **Especialista**: Tecnologia e conhecimento.
  - 🏹 **Explorador**: Sobrevivência e mobilidade.
  - 🎭 **Astuto**: Lábia e manipulação.
  - 🔮 **Místico**: Magia e o sobrenatural.
  - 🎨 **Artista**: Inspiração e criatividade.
- **Combate Mortal**: O sistema não infla os Pontos de Vida. Cada combate é perigoso e estratégico.

---

### 🤔 O que significa SIGMA?

SIGMA é a sigla para **Sistema Interpretativo e Genérico para Múltiplas Ambientações**. Este nome reflete os pilares centrais do sistema:

- **Interpretativo**:

  - Focado no papel do jogador como protagonista da narrativa.
  - Valorizando a criatividade e a interação entre os participantes.

- **Genérico**:

  - Adaptável a qualquer tipo de cenário, seja ele medieval, futurista, pós-apocalíptico ou qualquer outro.

- **Múltiplas Ambientações**:
  - Flexível o suficiente para atender às necessidades de mestres e jogadores, independentemente do universo ou gênero escolhido.

## 🚀 Como Rodar a Documentação

Esta documentação é construída usando **MkDocs**. Para rodar localmente e visualizar o manual completo:

1. **Instale o MkDocs** (caso não tenha):

   ```bash
   pip install mkdocs-material
   ```

2. **Rode o Servidor**:

   ```bash
   mkdocs serve
   ```

3. **Acesse**:
   Abra seu navegador em [http://127.0.0.1:8000](http://127.0.0.1:8000).
